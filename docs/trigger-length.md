# Trigger Length values

Decided 2026-11-10: Trigger Length uses **retrig-m4l's LEN list** (`../retrig-m4l`, `src/retrig.maxpat`, parameter LEN and its `coll ---len`), **capped at 32 steps** (no values above 32, no INF). That gives 95 values. The default is **1/16 (1 step)**, at index 14. Not built yet: v5 still has the provisional 10-value list.

- **Increments:** 0.125 to 2 steps in 1/16-step increments, then 0.125-step increments to 4, 0.25 to 8, 0.5 to 16, and 1 to 32. Labels follow retrig: fractions at the musical points (1/64, 1/32, 1/16, 1/8, 1/4, 1/2, 1/1), decimals elsewhere. 1 step = 1/16 note.
- **Half-ticks:** retrig stores lengths in half-ticks (1 step = 240) because the finest values aren't whole ticks (0.188 steps = 22.5 ticks). PitchBender's timer and envelope clock run in ticks. When this goes in, either confirm `delay` accepts fractional ticks (`delaytime 22.5 ticks`) and that `translate` handles them, or keep half-ticks and halve at the point of use.
- **Push:** like retrig, it stays a `live.menu`, so the labels are exact. Push moves a menu one entry per encoder click, with no acceleration, so going from 1 step to 32 steps takes about 80 clicks.
