# Trigger Length values

Decided 2026-11-10: **64 values from 0.25 to 32 steps** (1 step = 1/16 note):

- 0.25 to 8 steps in 0.25-step increments (32 values)
- 8.5 to 16 steps in 0.5-step increments (16 values)
- 17 to 32 steps in 1-step increments (16 values)

The default is **1/16 (1 step)**, at index 3. Labels come from retrig-m4l's LEN list, which contains every one of these values: fractions at the musical points (1/64, 1/32, 1/16, 1/8, 1/4, 1/2, 1/1), decimals elsewhere. Every value is a whole number of ticks (0.25 step = 30 ticks), so the timer needs no fractional ticks. It's a `live.menu`, so Push moves one entry per encoder click: from 1 step to 32 steps is 60 clicks. Built in v5.1.
